Learn French with me for a month!

Why?

I'm visiting Paris for the first time. I want to see how much French I can learn in a month while working full-time, trip planning, and going on unrelated travel for 10 of those days.

The Plan

Utilize an hour of my commute each weekday for comprehensible input and using mirroring to learn to make French sounds so my accent improves.

  • Finish reading Fluent Forever by Gabriel Wyner
  • 1 hour commute: listen to French
  • 30 min each weekday: build Anki vocabulary deck and practice recalling vocabulary and practice identifying minimal pairs (words that sound exactly the same minus one sound).
